2. What exists now

The repository contains a narrow TypeScript interface with one operation: submit( text, generation ). It returns an asynchronous stream of normalized AgentEvent values. Shared event shapes and reference diagrams also exist.

That is meaningful design evidence: the dependency boundary has a name, a location, and a typed contract. It is not yet production-adoption evidence.

4. How to study the plan

The sidebar shows only one level at a time. A red Excel-style corner means the task opens into smaller work. Choosing a task replaces this chapter with a dynamically generated lesson about that task. The complete hierarchy remains hidden.

Construction Principle Move one narrow boundary from planned, to active, to verified. Then let the evidence—not optimism—change its status to done.
