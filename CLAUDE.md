# spa_documentation

This nested Git repository is a plain HTML/CSS/JavaScript documentation SPA for
the parent `agent_blocks` workspace. It has no framework or build step. Run it
from this directory with `./start.sh` (optionally `./start.sh <port>`); the
default URL is `http://localhost:8931/index.html`.

Before doing any work here, load the `building-the-spa` skill from
`skills/building-the-spa/SKILL.md`. It defines the navigation drill-down,
directory layout, generated-page conventions, and verification workflow this
SPA depends on. Load it every time, not only when the task appears visual.
